Egy memórián belüli [handoff](./Handoff.md): az előző [session](./Session.md) historyja összefoglalásra kerül, és ez seedeli az új sessiont. Lossy — részletességet cserélünk headroomra. Indíthatja manuálisan a felhasználó vagy [automatically](./Autocompact.md) a harness.

*Usage:*

"[Context](./Context.md)'s getting heavy and I still have the test pass to do."

"Compact before you start — write what's load-bearing into the summary prompt so the new session keeps the schema decisions and drops the exploration."
